# Tesis-Maestr-a
Repositorio del componente computacional de una tesis de maestría, desarrollado para el procesamiento, análisis y visualización reproducible de señales fisiológicas y variables cinemáticas. Incluye el tratamiento de datos ECG, HR, RR, SpO₂, EMG y cinemática, junto con rutinas para la generación y organización de resultados experimentales.
